# `image-jsx`

## `renderToCanvas`

```ts
function renderToCanvas(canvas: Canvas, root: JSXChild);
```

Renders a JSX child to an existing Canvas.

## `render`

```ts
function render(width: number, height: number, root: JSXChild): Canvas;
```

Renders a JSX child to a new canvas of provided proportions, and returns the new canvas.

## `renderToFile`

```ts
function renderToFile(
  width: number,
  height: number,
  filename: string,
  root: JSXChild
);
```

Renders a JSX child to a new canvas of provided proportions, and saves the rendered result to a file.
