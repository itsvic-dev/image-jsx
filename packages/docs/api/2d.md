# `image-jsx/2d`

## Styles

Styles can be either CSS colors (`"#FF0000"`, `"red"`, etc.) or gradients.

See also [`linearGradient`](./main.md#lineargradient).

## `Rect`

`Rect` renders a rectangle that contains its children.

It's important to note that **`Rect` does not handle layouts.** It merely
renders a background. Your children will be rendered on top of one another.

```tsx
<Rect fill="white">
  <Text>hello!</Text>
</Rect>
```

### Properties

| Name     | Type      | Description           |
| -------- | --------- | --------------------- |
| `fill`   | `Style?`  | [Fill style](#styles) |
| `w`      | `number?` | Width                 |
| `h`      | `number?` | Height                |
| `x`      | `number?` | Horizontal position   |
| `y`      | `number?` | Vertical position     |
| `radius` | `number?` | Corner radius         |

## `Text`

`Text` renders a piece of text.

```tsx
<Text fontFamily="Arial" fontSize={16} fill="white">
  hello!
</Text>
```

### Properties

| Name         | Type      | Description                  |
| ------------ | --------- | ---------------------------- |
| `fill`       | `Style?`  | [Fill style](#styles)        |
| `fontFamily` | `string`  | Font family                  |
| `fontSize`   | `number`  | Font size in pixels          |
| `fontWeight` | `number?` | Font weight, defaults to 400 |
| `x`          | `number?` | Horizontal position          |
| `y`          | `number?` | Vertical position            |

## `Layout`

`Layout` automatically arranges children into a layout, similar to a flexbox.

```tsx
<Layout>
  <Text fontFamily="Arial" fontSize={16} fill="white">
    hello!
  </Text>
  <Rect fill="red" w={16} h={16} />
</Layout>
```

### Properties

| Name          | Type                           | Description                                  |
| ------------- | ------------------------------ | -------------------------------------------- |
| `direction`   | `'vertical' \| 'horizontal'`   | Layout direction                             |
| `alignment`   | `'start' \| 'middle' \| 'end'` | Alignment of items on the layout axis        |
| `arrangement` | `'start' \| 'middle' \| 'end'` | Alignment of items on the perpendicular axis |
| `x`           | `number?`                      | Horizontal position                          |
| `y`           | `number?`                      | Vertical position                            |
| `w`           | `number?`                      | Minimum width                                |
| `h`           | `number?`                      | Minimum height                               |
| `gap`         | `number?`                      | Gap between children, in pixels              |
